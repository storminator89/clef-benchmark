# Recovery sources and rights

The 72 fictional cases were newly AI-authored on 2026-10-02, without customer records or third-party utterance corpora. The exact model-visible file was reconstructed from retained authoring text and verified against its previously recorded SHA-256; this preserves the original scientific inputs without claiming recovery of unavailable raw logs or the old full preparation archive.

The native policy and model/runtime reference files were fetched read-only from the user's public project at immutable commit80f407f08a7c4e2680c455718e117cfe7a64d96e: https://github.com/storminator89/clef-benchmark/tree/80f407f08a7c4e2680c455718e117cfe7a64d96e . Native runner and encoder match the exact historical SHA-256 values. The project's own code/synthetic-data license is Apache-2.0; upstream Cloudflare licensing and notices are retained separately. No model weights are redistributed in recovery bundles.

Official model: https://huggingface.co/Cloudflare/clef-flash/tree/17f0b0ad64efb65d273590632833508766b2aae6 . All downloaded model files must match the pinned public manifest before use. Official dependency setup uses the CPU PyTorch package index and exact frozen Python package versions.

The scoped HF_HOME location is a documented file-cache configuration: https://huggingface.co/docs/huggingface_hub/package_reference/environment_variables . It keeps newly downloaded assets under the writable task workspace and changes neither model bytes nor inference backend. No login, credentials, payment, security-policy changes or private-user data transmission is involved.

Independent AI review is not qualified human review. Constructed colloquial abbreviations/code-switching are not representative German speech, a dialect corpus or real bank/insurance policy. The rules describe a fictional closed world only.
