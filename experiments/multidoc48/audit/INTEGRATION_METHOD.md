# Scientific audit and public curation

All 61 pre-inference frozen files are preserved byte for byte, including the
canonical model release and package pins. Native requests, gold, all 48 predictions
and unrounded option vectors, all case scores, all 24 errors and the original result
summary are unchanged. This integration performed no model loading or inference.

The frozen independent checker does not import the primary scorer. It rereads the
visible rules, verifies all native choices and vectors, recomputes each diagnostic,
aggregate and slice, compares full error evidence, and checks run chronology and
input order. The compact completed-run audit records those conclusions. The
separate exhaustive semantic error review remains available.

## Corrections made before inference

The initial independent semantic review found design shortcuts from document count,
source-ID association and unbalanced positions. All cases were changed to contain
three documents, with explicitly excluded distractors where needed. IDs and
positions were counterbalanced within gold outcome groups. No determination label
changed. Sixteen shared templates and twelve descriptive families remain dependent.

Scoring checks tightened native four-decimal confidence validation and added shared
template slices. Report tests were extended to partial and unavailable timings.
The independent checker aligned its descriptive slices and used scientific-role
hash labels while adding run-order, chronology and preflight checks. These were
pre-inference methodology corrections, not post-outcome gold or prediction repairs.
The frozen review history retains the full scientific evidence.

## Public scope

Public curation retains canonical scientific evidence and concise final validation.
Redundant development diagnostics, duplicate runtime inventories and operational
bookkeeping are outside this artifact. Curation notes describe scope only, without
identities or hashes of excluded material. FILE_SHA256.json is an allowlist of the
retained files. Every error is retained.

The source field and final determination are distinct. not_unique plus yes/no is
correct when every plausible complete document yields the same answer. The
unresolved stratum contains definite controls and must not define clarification
denominators. Cases are purposively AI-authored and separately AI-reviewed, not
human-expert validated or IID. Position balance is not an order-swap intervention.
Native marginal scores are neither calibrated correctness nor joint probability.
