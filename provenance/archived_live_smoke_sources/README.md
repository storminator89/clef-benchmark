# Historical HTTP-smoke sources

These exact source bytes were used by the already recorded genuine smoke in `qa/live_multifield_smoke.json`. They are archived for audit, **not current runtime code and not a claim that later changes were executed**. Every archived file is checked against the original, unchanged proof hash.

Do not import or run these copies as the current backend. The current source evolution is separately bounded by `provenance/workbench_evolution.json`; a new current-source smoke requires a separate actual run and evidence file. Frozen vendor code, model configuration/manifests and benchmark outputs remain immutable in their original locations.
